FEATURES

功能

临时隧道

免登录、免凭证，启动后得到一个 *.trycloudflare.com 地址。

固定隧道

使用自己的域名，隧道与配置保存在本地，可随时修改 ingress 规则。

DNS 路由

按隧道列出已绑定的域名，点击复制，可改名或解绑。

密码锁

为域名加一层 Cloudflare Access 校验，未带凭据的连接返回 403。

客户端桥接

把远端隧道映射到本机端口，多条连接可同时运行。

协议覆盖

HTTP、HTTPS、TCP、UNIX、UNIX + TLS 与 Hello World。

安装 cloudflared

识别系统与 CPU 架构，从官方 Release 下载对应版本。

深浅主题

Win11 风格界面，深色与浅色主题随时切换。

QUICK START

快速开始

  1. 1

    安装 cloudflared

    配置 → 安装 cloudflared

  2. 2

    授权登录

    配置 → Cloudflared 授权登录，选中要授权的域名

  3. 3

    创建隧道

    服务端 → 固定 / 临时隧道 → 创建，填协议与本机端口

  4. 4

    启动

    点列表行的 ▶，临时隧道给出临时域名，固定隧道使用自己的域名
